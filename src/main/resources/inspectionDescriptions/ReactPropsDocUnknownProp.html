Reporta props que el componente no acepta, por ejemplo <Button text="Buscar" /> en MUI (Button no tiene text: el texto no se muestra).

En componentes de librería (MUI) se consideran sus props, las heredadas y los atributos HTML válidos; no se revisan los que usan MUI System (Box, Typography, Grid, Stack). En componentes propios solo se revisa cuando se conocen todas las props que usa (sin ...rest ni {...props}).

Correcciones: cambiar por una prop de nombre parecido, usar el texto como contenido (children) o quitarla.
